# Super Mario Galaxy 2 reference sources

RVL SDK sources and headers from [SMGCommunity/Garigari](https://github.com/SMGCommunity/Garigari)
(CC0 1.0, see LICENSE). Used for SDK modules missing from the Xenoblade sources (BTE, VI, NAND, KPAD,
NWC24, THP, …) and for files whose 2010 version is closer to The Last Story's. Only units listed in
`config/SLSP01/libs_ref.json` (names starting with `smg2/`) are built.
