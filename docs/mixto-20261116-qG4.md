## Hallazgos (para docs/trucos-mwcc.md)

- Un union anonimo (o struct anonimo) en una cabecera consume `@N` en cada unidad que la incluye, como un
  parametro con nombre: renumera los datos de otras unidades (labelcheck peor). (mixto-20261116 qG4)
- Cadena de `||` con cada resultado materializado (`cmpwi rX, 0; li rY, 0; bne set; <cond>; ble skip; set: li
  rY, 1`): sentencias `bad = bad || cond;` una por linea; el primer valor con `li 1; bgt; li 0` sale de una
  inline `bool over = true; if (v <= limit) over = false; return over;`, y un paso con `mfcr; extrwi. 1, 1`
  de una inline que devuelve `int` (`return speed > 1.5f;`; con `bool` cambian los registros). Las pruebas de
  bits de una palabra `int` con `cmplwi` necesitan el cast a `unsigned int`. (mixto-20261116 qG4)
- Pop de un `atn::FixedArray_unk` con la base del objeto (`lwzx v, &arr, size*4`): `*(list.end() - 1)` y
  despues `list.mSize--`; `list[list.size() - 1]` o `list[--list.mSize]` no pliegan la base. El erase con el
  indice recalculado (`slwi; srawi; addze`) sale de `pool.erase(pool.begin() + r)`, no de `&pool[r]`.
  (mixto-20261116 qG4)
- Copia en bucle entre dos arrays indexados por el mismo desplazamiento (`add r5, mgr, off; add r6, net, off`):
  acceder al destino por una inline que devuelve la referencia (`PPNetPlayer_unk(mgr, i) = net->mPlayers[i]`);
  directo, MWCC avanza un puntero para el destino. (mixto-20261116 qG4)
