## Hallazgos

- `atn::Abs_unk(x)` (dos niveles) da `fabs fA; frsp fB, fA` con fA != fB donde `__fabs` reutiliza el registro
  (BattleTask fn_800FBA9C).
- Una inline de cabecera con `if (...) return 255; if (...) return 0; return ...;` frente a la misma logica como
  expresion condicional cambia el reparto de registros de quien la llama varias veces (ToU32); guardar la
  condicional en un local antes del `return` no cambia el codigo pero sube el coste de inlining (D2A_Window::vf18
  deja de inlinear ToU32).
- Una funcion miembro inlineada automaticamente (con `-ipa file`) puede salir con otro reparto de registros que su
  copia suelta en el original; una `static inline` gemela con otro orden de declaracion de locales cierra la que
  la llama (GameTask fn_80375D0C / fn_803754F0).
- Busqueda lineal en un vector de un miembro: la forma con el puntero al array leido dentro del bucle
  (`T* data = v.mData; if (id == data[i].mId) return &data[i];`) da el reparto del original (GameTask
  fn_80374710, como Em208Queen).
- Cambiar el cuerpo de una inline de cabecera renumera los `@N` de todas las unidades que la incluyen (Color.h:
  ~335 unidades). `refmap.py` empareja por indice de linea: falla si el `symbols.txt` de mainref tiene otro
  numero de lineas; emparejar por direccion.
