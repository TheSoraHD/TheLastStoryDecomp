## Hallazgos

- Copia de un miembro string a traves de un alias `basic_string& self = *this` en el `operator=` inline: MWCC usa la
  direccion calculada (`addi r3, r30, 0x14`) como base de las escrituras en vez de plegar el desplazamiento
  (`0x14(r30)`); sin probar el bit largo una vez en un local, la segunda prueba se recarga (AudioDevice). (tokenizer::assign)
- Un swap de un tamano que se acaba de poner a 0 recarga el campo en nuestro MWCC; el original guarda el 0 conocido:
  escrito como movimiento (`a = b; b = 0`) sale como el original (ShaderManager, ParseARNU).
- Para encontrar la funcion enlazada que rompe el DOL tras un cambio de cabecera: `nm -n main.elf` frente a
  `symbols.txt`, la primera funcion desplazada sigue a la que crecio.
