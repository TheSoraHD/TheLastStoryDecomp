## Hallazgos

- MWCC: `if (cond) return TRUE; else return FALSE;` en una inline se materializa como `li r0,1; b; li r0,0; cmpwi` en el llamador; `return a && b;` o un local `BOOL` no (DWC_ReportFriendData).
- MWCC: llamar a una inline un nivel menos profundo (`DWCi_Acc_LoginIdToUserName` directa en vez de `DWC_LoginIdToUserName`) invierte el orden en pila de sus arrays locales.
- MWCC (todas las versiones Wii): un `switch` pequeno compara y coloca los cuerpos en el orden del fuente; si el original compara en otro orden que el de sus cuerpos, no es un `switch` simple.
- MWCC: el ternario `s != 0 ? strlen(s) : 0` dentro de dos niveles de inline coloca primero el bloque del 0; en el llamador directo, primero el de `strlen` (String_unk de EventParser_unk).
