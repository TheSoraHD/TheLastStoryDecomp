## Hallazgos (para docs/trucos-mwcc.md)

- Un `return -1` repetido en varias salidas sale duplicado (`li r3,-1; b`); un `goto` a una sola salida da el
  `li r3,-1` compartido del original (PacketPack fn_804EDB0C 94 -> 99,5 %).
- Una comprobacion `if (p == 0) return 0; if (a != X || b != 5) return 0; return 1;` en una inline da el orden de
  saltos del original; `if (a == X && b == 5) return 1;` lo invierte (fn_804ED768 99,86 -> 100 %).
- `sizeof` de la pila: un FixedArray local de capacidad desconocida se deduce del marco (`stwu`); fn_804DDA04 = 20.
- El fold de `strlen("")` no atraviesa una inline: `strlen(s)` con `s = ""` pasado a una inline se llama de verdad.
  Tampoco `*s`/`s[0]` sobre `""` (referencian el literal). Sigue sin haber patron natural para los `""` muertos.
- Lineas con literales en una inline de cabecera renumeran los `@N` de todas las unidades que la incluyen aunque no la
  usen: definir la inline en los .cpp que la usan.
