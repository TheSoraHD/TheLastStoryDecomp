## Hallazgos (para docs/trucos-mwcc.md)

- `-str reuse` fusiona cadenas iguales solo dentro de una funcion: cada funcion que usa `""` aporta el suyo a
  `@stringBase0` (PacketPack tiene 6).
- El literal de una inline entra en el pool cuando se usa la inline, no donde esta su texto.
- Una inline variadica vacia no se inlinea (se llama): conserva el literal pero emite un `bl`.
- `strlen("")` que MWCC pliega a 0 deja el `""` en `@stringBase0` sin referencia y en su sitio (prueba suelta:
  `use("%d"); if (strlen("") == 0) use("x");` da `"%d" "" "x"`). Es el unico patron encontrado para los `""`
  muertos de PacketPack; no se ha aplicado por no saber que codigo real lo producia.
- Una condicion `a >= 0 && a < 60` guardada en un `bool` antes del `if` reproduce el valor materializado
  (`srwi`/`xori`) del original (fn_804DA690 94,7 -> 95,9 %).

## Bloqueos (para docs/mwcc-blockers.md)

- `""` muerto en `@stringBase0` (PacketPack 0x150 y 0x18D): probados local sin usar, `if (0)`, inline con
  parametro sin usar, ternario `i ? "" : ""`, objeto local con ctor, `char b[8] = ""`, `strcpy/strcat/sprintf`
  con `""` (estos lo referencian); solo `strlen("")` plegado lo deja (ver Hallazgos).
